# synkit 샘플 리포트

스키마(비식별 메타정보)만으로 정답이 붙은 **합성 문서**를 만들고, 추출 결과를 정답으로 채점하는 CLI 도구 `synkit`(가칭)이 만든 리포트의 샘플입니다.

- **[샘플 리포트 열기](https://hansol418.github.io/synkit-demo/)** (이 저장소의 `index.html`)
- 리포트는 한계 고지가 첫 섹션이고, 외부 파일이나 스크립트 없이 열리는 단일 HTML 파일입니다. 다크 모드, 인쇄, 휴대폰 폭을 지원합니다.

## 꼭 알아둘 것

- 이 리포트의 **모든 데이터는 합성(가상)** 입니다. 실제 문서나 실제 레코드가 아닙니다.
- 점수는 **합성 데이터 기준**이며 실제 문서에서의 성능을 보증하지 않습니다. 리포트 첫 섹션에 같은 내용이 있습니다.
- 채점에 쓴 추출기는 정규식 기반 간이 추출기이며 LLM 추출의 성능을 대표하지 않습니다.
- `synkit` 본체의 코드와 문서는 비공개 저장소에 있고 이 저장소에는 없습니다. 이 저장소에는 샘플 리포트 한 개만 있습니다.

## 어떻게 만들었나

`init → validate → generate → render → (간이 추출) → grade → check → report`를 한 번에 돌리는 종단 데모(시드 7)의 결과입니다. 같은 시드와 스키마면 같은 데이터가 나옵니다.
