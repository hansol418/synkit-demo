# synkit 체험

스키마(가상의 설정)만으로 정답이 붙은 **합성 문서**를 만들고, 추출 결과를 정답과 대조해 **채점**하는 도구 `synkit`(가칭)을 브라우저에서 직접 돌려 볼 수 있는 페이지입니다.

**https://hansol418.github.io/synkit-demo/**

버튼 하나로 `스키마 검증 → 합성 데이터 생성 → 합성 문서(Excel·Word) 만들기 → 추출 → 채점 → 점검 → 리포트`가 돌고 결과가 화면에 나옵니다. 시드, 문서 수, 표기 변형·오타·누락 비율을 바꿔 다시 실행할 수 있고, 추출 결과는 세 가지 중에 고릅니다.

- **문서를 실제로 읽어 추출:** 규칙 기반 간이 추출기가 만들어진 문서를 읽습니다.
- **정답 그대로 제출:** 채점기가 100%를 주는지 확인합니다.
- **일부러 틀리게 제출:** 오추출·미검출·환각·형식 오류를 원하는 개수만큼 넣고, 채점기가 정확히 같은 개수를 찾는지 봅니다.

## 어떻게 동작하나

실제 synkit 코드(스키마, 생성, 문서 렌더링, 채점, 점검, 리포트)가 [Pyodide](https://pyodide.org)(브라우저용 파이썬)로 **방문자의 브라우저 안에서** 실행됩니다. 서버가 없고, 입력과 결과는 어디로도 전송되지 않습니다. 파일은 브라우저 메모리에만 생깁니다.

- 처음 열 때 파이썬 엔진과 라이브러리(`pydantic`, `PyYAML`, `Jinja2`, `lxml`은 Pyodide에서, `openpyxl`·`python-docx`는 PyPI에서)를 인터넷에서 받아 오므로 10~30초가 걸립니다.
- 이 저장소에는 페이지(`index.html`, `app.js`), 연결 코드(`glue.py`), 데모용 간이 추출기(`synkit_demo_extractor.py`), 그리고 synkit의 핵심 코드 압축 파일(`synkit.zip`)이 있습니다. DB 연동(로그인·올리기) 코드와 기획 문서는 비공개 저장소에 있고 여기에는 없습니다.

## 꼭 알아둘 것

- 모든 데이터는 **합성(가상)** 입니다. 점수는 합성 데이터 기준이며 실제 문서에서의 성능을 보증하지 않습니다. 페이지 맨 위에 같은 고지가 있습니다.
- 간이 추출기는 정규식 기반이라 LLM 추출의 성능을 대표하지 않습니다.
- 양식은 3종(표·서술·병합 표)뿐이고 스캔 품질이나 비정형 서술은 재현하지 못합니다.
- 라이선스를 정하지 않았습니다. 코드를 다른 곳에 가져다 쓰지 말아 주세요.
